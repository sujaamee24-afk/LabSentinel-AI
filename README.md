# LabSentinel-AI                                                                                                                                                      # LabSentinel AI – Multimodal Intelligent Laboratory Safety Agent

## About the Project
LabSentinel AI is an AI-powered laboratory safety monitoring system designed to identify potential hazards and support safer laboratory environments. It combines multimodal inputs, including camera images, environmental sensor readings, and voice or text incident reports, to assess risks and recommend appropriate safety actions.

The project aims to make laboratory safety monitoring more intelligent by combining different sources of information instead of relying only on individual sensor alerts.

## Problem Statement
Laboratories may face hazards such as gas leakage, smoke, and abnormal temperature conditions. Traditional monitoring systems often depend on individual sensors or fixed threshold alarms, which may not provide sufficient context about a potential incident.

## Our Solution
LabSentinel AI combines multiple types of input to support laboratory hazard assessment. It can help users:
- Review camera images for potential visible hazards.
- Monitor temperature, humidity, and gas sensor readings.
- Submit incidents through voice or text descriptions.
- Assess potential risk levels based on available information.
- Receive recommended safety actions.
- Generate structured incident reports.

## Key Features
- **Multimodal Monitoring:** Uses image, sensor, and voice/text inputs.
- **AI-Assisted Risk Assessment:** Helps identify and classify potential hazards.
- **Safety Recommendations:** Provides suggested actions based on the reported situation.
- **Incident Reporting:** Organizes incident details into a structured report.
- **Dashboard:** Presents monitoring information and assessment results in one place.

## How It Works
1. The user provides available sensor readings, an image, or a voice/text incident report.
2. The system analyzes the supplied information using the implemented assessment logic.
3. Potential hazards and risk levels are displayed on the dashboard.
4. The system presents relevant safety recommendations.
5. An incident report can be generated for review.
